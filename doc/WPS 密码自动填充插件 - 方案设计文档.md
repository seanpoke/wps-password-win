## 1.2 产品概述

本产品为 Windows 桌面端独立后台插件，无主界面、无 WPS 内部插件注入、无第三方运行环境依赖，以 **Win10（64 位）+WPS Office 12.1.0.25225（64 位）** 为双核心开发与适配基准。

插件通过系统级 API 实现 WPS 进程、对话框、控件的实时监控与定位，模拟人为键鼠操作完成**加密时强密码一键生成 / 填充**、**打开时密码自动读取 / 填充**，并将密码写入 / 读取自 WPS 文档的自定义元数据中，彻底解决用户记忆、传递 WPS 加密文档密码的痛点。

产品支持单安装包一键分发，用户零配置即可使用，同时对 Windows 7/11、WPS 2019/2021 保持向下兼容，核心功能全程可用，满足企业日常办公的密码自动化管理需求。

## 1.3 核心功能需求

### 1.3.1 加密文档：一键生成填充密码 + 写入元数据

1. **加密对话框智能识别**：插件后台静默运行，实时监控 WPS 进程，自动识别 WPS 文字中「文档加密」「另存为加密」触发的密码输入对话框，无人工干预，双基准环境下识别响应时间≤100ms。
2. **悬浮按钮精准展示**：识别到密码输入框后，在输入框**右侧 5px 紧贴位置**显示无边框、置顶的「一键生成密码」悬浮按钮，按钮尺寸与 WPS 密码框高度匹配，Win10 下适配 100%/125%/150% DPI 缩放，无偏移、无遮挡。
3. **强密码一键生成与填充**：点击悬浮按钮后，自动生成 16 位符合规范的强密码，同步填充至 WPS「密码」和「确认密码」双输入框，填充过程模拟人为打字，WPS 无感知。
4. **密码自动写入元数据**：用户在 WPS 中完成加密并保存文档后，插件自动识别文档本地路径，将生成的密码写入文档**隐藏式自定义元数据**（属性名固定），元数据随文档存储，无外部泄露风险，双基准环境下写入成功率 100%。

**强密码规范**：16 位字符，包含大写字母、小写字母、数字、指定特殊符号（!@#$%^&*），四类字符各至少 2 位，无连续 / 相似字符，随机无重复。

### 1.3.2 打开加密文档：自动读取元数据 + 填充密码打开

1. **解密对话框智能识别**：插件后台监控 WPS 进程，自动识别打开加密 docx 文档时弹出的「密码输入」解密对话框，双基准环境下识别响应时间≤100ms。
2. **文档路径自动解析**：识别到解密对话框后，插件无需人工操作，自动解析待打开文档的本地绝对路径。
3. **元数据密码精准读取**：根据解析的文档路径，插件自动读取文档自定义元数据中的密码信息，双基准环境下读取成功率 100%。
4. **密码自动填充并打开**：读取密码后，插件模拟人为操作将密码输入至解密密码框，随后自动模拟点击「确定」按钮，实现文档**无感知秒开**，全程无人工干预，双基准环境下填充 + 打开响应时间≤300ms。

## 1.4 异常处理需求

所有异常处理均遵循**不干扰用户手动操作**原则，仅在必要时进行轻量提示，提示框自动关闭，不阻塞 WPS 流程。

1. **密码框 / 对话框识别失败**：因版本兼容、系统环境等原因导致无法识别 WPS 密码框 / 加密 / 解密对话框时，插件不做任何操作，完全放行用户手动操作，无任何提示。
2. **元数据读取失败**：文档元数据中无本插件写入的密码属性（如非本插件加密的文档、元数据被篡改），插件弹出**3 秒自动关闭的轻量提示框**，提示「请手动输入文档密码」，无其他操作。
3. **文档格式不兼容**：识别到非 docx 格式的 WPS 加密文档（如 doc/wps）或非 WPS 文字文档，插件不做任何操作，不干扰用户手动处理。
4. **文档被占用**：读取 / 写入元数据时检测到文档被 WPS 或其他程序占用，插件自动重试 3 次（每次间隔 500ms），重试失败则按「元数据读取失败」规则处理。
5. **悬浮按钮误触**：悬浮按钮仅鼠标悬停时高亮，点击 WPS 空白区域自动隐藏；支持右键点击悬浮按钮选择「临时隐藏」，再次识别到密码框时自动恢复显示。

## 1.5 非功能需求

### 1.5.1 运行环境需求

1. 插件为**单文件安装包**，用户安装时无需提前安装 Python、.NET、Office 等任何第三方运行环境 / 组件，一键安装即可使用。
2. 插件支持 Windows 系统默认权限，Win10 下仅需**普通管理员权限**，无需系统级最高权限。
3. 插件无网络依赖，全程离线运行，无后台数据上传，密码仅存储在文档元数据中，无本地文件存储。

### 1.5.2 易用性需求

1. **一键安装**：安装包双击运行，自动完成安装、创建桌面快捷方式，支持开机自启（安装时可选勾选），无手动配置步骤。
2. **静默运行**：插件运行后仅在系统托盘显示图标，无主界面，后台静默运行，不占用桌面空间，支持右键托盘图标进行「打开安装目录」「退出插件」操作。
3. **零学习成本**：插件操作逻辑贴合用户原有 WPS 加密 / 打开习惯，仅新增「一键生成密码」悬浮按钮，用户无需额外学习操作。

### 1.5.3 性能需求

1. **资源占用**：双基准环境下，插件运行时 CPU 占用≤3%，内存占用≤40MB；兼容环境下，CPU 占用≤5%，内存占用≤50MB，不影响 WPS 及其他程序运行。
2. **响应速度**：双基准环境下，对话框识别≤100ms，密码填充 + 按钮点击≤200ms，整体加密 / 打开自动化流程响应时间≤300ms；兼容环境下，整体响应时间≤500ms。
3. **稳定性**：双基准环境下，插件持续运行 72 小时**零崩溃、零内存泄漏、零核心功能失败**；兼容环境下，单日异常退出次数≤0，核心功能失败率≤0.1%。

## 1.6 产品使用场景

### 场景 1：员工在双基准环境下加密新 WPS docx 文档

员工在 Win10 系统的 WPS 12.1.0.25225 中编辑 docx 文档，选择「文件 - 加密」触发密码对话框，插件自动在密码框右侧显示「一键生成密码」悬浮按钮，点击后自动生成并填充 16 位强密码，员工直接点击 WPS「确定」完成加密并保存，插件自动将密码写入文档元数据，员工无需记忆密码。

### 场景 2：员工在双基准环境下打开本插件加密的文档

员工在 Win10 系统的 WPS 12.1.0.25225 中双击打开由本插件加密的 docx 文档，插件识别到解密对话框后，自动读取文档元数据中的密码，填充并点击「确定」，文档无感知秒开，员工无需手动输入密码。

### 场景 3：员工在兼容环境下使用插件核心功能

员工在 Windows 7 的 WPS 2021 中加密 / 打开 docx 文档，插件识别到对话框后，完成密码生成 / 填充、元数据读写的核心功能，虽悬浮按钮适配性略有差异，但不影响操作，全程无需手动输入密码。

### 场景 4：员工接收他人通过本插件加密的文档

员工从企业微信 / 邮件接收他人用本插件加密的 docx 文档，本地双击打开后，插件自动完成密码读取、填充、打开，无需向发送方询问密码，跨环境（基准 / 兼容）均支持。
