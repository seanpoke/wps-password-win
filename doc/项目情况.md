# 项目情况

## 1. 项目概述

WPS 密码自动填充插件是一个 Windows 桌面端独立后台插件，无主界面、无 WPS 内部插件注入、无第三方运行环境依赖，以 **Win10（64 位）+WPS Office 12.1.0.25225（64 位）** 为双核心开发与适配基准。

插件通过系统级 API 实现 WPS 进程、对话框、控件的实时监控与定位，模拟人为键鼠操作完成**加密时强密码一键生成 / 填充**、**打开时密码自动读取 / 填充**，并将密码写入 / 读取自 WPS 文档的自定义元数据中，彻底解决用户记忆、传递 WPS 加密文档密码的痛点。

## 2. 技术背景

- **开发框架**：.NET 6
- **开发工具**：Visual Studio 2022
- **WPS 技术栈**：WPS 使用 Qt 框架开发，窗口类名为 `Qt5QWindow`，传统的 `FindWindowEx` 函数无法直接找到子控件
- **核心技术**：
  - Win32 API 用于窗口监控和控制
  - 模拟键盘和鼠标事件
  - 文档元数据读写
  - 进程和窗口监控

## 3. 已实现功能

### 3.1 核心功能

1. **加密文档**：
   - 自动识别 WPS 加密对话框
   - 显示「一键生成密码」悬浮按钮
   - 生成 16 位强密码并填充至双输入框
   - 自动将密码写入文档元数据

2. **打开加密文档**：
   - 自动识别 WPS 解密对话框
   - 解析文档路径
   - 读取文档元数据中的密码
   - 自动填充密码并打开文档

### 3.2 辅助功能

1. **系统托盘**：
   - 显示系统托盘图标
   - 支持退出和打开文件夹操作

2. **悬浮按钮**：
   - 在密码框右侧显示
   - 支持鼠标悬停高亮
   - 仅在加密对话框中显示

3. **提示框**：
   - 自动关闭
   - 轻量提示

4. **日志管理**：
   - 详细的运行日志记录
   - 不同级别的日志记录

## 4. 技术亮点

1. **跨平台兼容性**：支持 Windows 7/10/11 系统
2. **版本兼容性**：支持 WPS 2019/2021 和 WPS 12.1.0.25225 版本
3. **无侵入性**：通过系统级 API 实现，无需 WPS 内部插件依赖
4. **安全性**：密码仅存储在文档元数据中，无外部存储
5. **用户友好**：提供悬浮按钮，操作简单直观
6. **稳定性**：完善的异常处理机制，确保插件稳定运行
7. **Qt 窗口支持**：专门针对 WPS 的 Qt 框架进行了优化，提高了窗口和控件识别的准确性

## 5. 关键技术实现

### 5.1 窗口识别与控件定位

- 实现了 WPS 进程监控功能
- 实现了窗口识别功能，支持识别「文档加密」和「密码加密」窗口
- 实现了控件定位功能，支持递归查找子窗口
- 针对 Qt 窗口进行了专门优化，添加了 `FindQtEditControl` 方法

### 5.2 模拟操作

- 实现了键盘模拟功能，支持密码输入模拟
- 实现了鼠标模拟功能，支持按钮点击模拟
- 实现了窗口管理功能，确保窗口在前台

### 5.3 文档元数据管理

- 实现了文档元数据读写功能
- 密码仅存储在文档元数据中，无外部存储

## 6. 项目结构

- `WpsPasswordManager/Program.cs`：主程序逻辑
- `WpsPasswordManager/Monitor/WpsMonitor.cs`：窗口监控和控制
- `WpsPasswordManager/Simulator/InputSimulator.cs`：输入模拟
- `WpsPasswordManager/Business/MetadataManager.cs`：文档元数据处理
- `WpsPasswordManager/UI/FloatingButton.cs`：悬浮按钮
- `WpsPasswordManager/UI/TrayIcon.cs`：系统托盘
- `WpsPasswordManager/Utils/Logger.cs`：日志功能

## 7. 注意事项

1. **兼容性**：插件优先适配 Win10（64 位）+WPS Office 12.1.0.25225（64 位）环境，向下兼容 Windows 7/11 和 WPS 2019/2021

2. **稳定性**：任何修改不得影响现有功能的稳定性和完整性

3. **安全性**：密码仅存储在文档元数据中，无外部存储，确保密码安全

4. **性能**：插件运行时 CPU 占用≤3%，内存占用≤40MB（双基准环境）

5. **响应速度**：对话框识别≤100ms，密码填充 + 按钮点击≤200ms，整体加密 / 打开自动化流程响应时间≤300ms（双基准环境）
