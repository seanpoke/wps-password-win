# WPS 密码自动填充插件项目文档

## 1. 项目概述

### 1.1 项目背景

在日常办公中，用户经常需要处理大量的WPS文档，其中许多文档都设置了密码保护。每次打开这些文档时，用户都需要手动输入密码，这不仅繁琐，而且容易忘记密码。为了解决这一问题，我们开发了WPS密码自动填充插件，旨在为用户提供便捷的密码管理和自动填充功能。

### 1.2 项目目标

- 自动检测WPS文档的密码加密窗口
- 提供密码生成功能，创建安全的随机密码
- 自动填充密码到解密窗口
- 自动保存密码到文档元数据
- 提供用户友好的界面和操作体验

### 1.3 主要功能特点

- **密码生成**：生成符合安全标准的随机密码
- **自动填充**：自动检测并填充密码到WPS解密窗口
- **密码管理**：自动保存密码到文档元数据
- **悬浮按钮**：在密码加密窗口显示便捷操作按钮
- **系统托盘**：提供系统托盘图标和上下文菜单
- **登录验证**：支持用户登录验证
- **实时监控**：实时监控WPS进程和窗口

### 1.4 适用范围

本插件适用于Windows操作系统上的WPS Office应用，支持以下文件格式：
- .docx, .doc
- .xlsx, .xls
- .pptx, .ppt

## 2. 技术架构

### 2.1 系统整体架构设计

项目采用模块化设计，主要包含以下核心模块：

1. **监控模块（Monitor）**：负责监控WPS进程和窗口，定位密码对话框和输入框
2. **业务模块（Business）**：包含密码生成和元数据管理功能
3. **输入模拟模块（Simulator）**：负责模拟键盘输入和鼠标操作
4. **UI模块**：提供系统托盘、悬浮按钮和登录界面
5. **工具模块（Utils）**：提供日志记录和全局状态管理

### 2.2 技术栈选型

| 类别 | 技术/框架 | 版本 | 用途 |
|------|----------|------|------|
| 开发语言 | C# | .NET 6.0 | 主要开发语言 |
| UI框架 | Windows Forms | - | 提供用户界面 |
| 外部依赖 | DocumentFormat.OpenXml | 2.20.0 | 处理Office文档元数据 |
| 系统API | Win32 API | - | 窗口操作和输入模拟 |
| 网络 | HttpClient | - | 登录验证 |
| 数据存储 | 本地文件 + NTFS备用数据流 | - | 存储密码和元数据 |

### 2.3 架构优势

- **模块化设计**：各模块职责明确，便于维护和扩展
- **低耦合**：模块间通过明确的接口通信，降低依赖
- **实时响应**：采用多线程监控，实时响应WPS窗口事件
- **安全性**：密码存储在文档元数据中，避免明文存储
- **兼容性**：支持多种WPS窗口类型和文件格式
- **用户友好**：提供直观的操作界面和便捷的功能

## 3. 核心功能模块说明

### 3.1 监控模块（Monitor）

**功能描述**：监控WPS进程和窗口，定位密码对话框和输入框，获取窗口信息。

**职责划分**：
- 检测WPS进程是否运行
- 查找密码加密和解密对话框
- 定位密码输入框和确认密码输入框
- 查找应用按钮
- 获取窗口文本和位置信息
- 解析文档路径

**核心实现逻辑**：
- 使用Win32 API函数`FindWindow`和`FindWindowEx`查找窗口
- 枚举所有WPS窗口，识别密码相关窗口
- 递归查找子窗口，定位输入控件
- 使用多种方法尝试定位窗口，提高成功率

**关键类**：`WpsMonitor`

### 3.2 业务模块（Business）

**功能描述**：包含密码生成和元数据管理功能。

**职责划分**：
- 生成安全的随机密码
- 读取和写入文档元数据
- 管理文档UID
- 处理外部密码存储

**核心实现逻辑**：
- 密码生成：使用随机算法生成包含大小写字母、数字和特殊字符的密码
- 元数据管理：使用Windows NTFS备用数据流存储密码和UID
- UID管理：为每个文档生成唯一标识符，用于追踪和管理

**关键类**：`PasswordGenerator`, `MetadataManager`

### 3.3 输入模拟模块（Simulator）

**功能描述**：模拟键盘输入和鼠标操作，实现密码填充和快捷键操作。

**职责划分**：
- 模拟密码输入到输入框
- 模拟键盘快捷键（如Ctrl+S）
- 模拟鼠标点击操作
- 清空输入框内容

**核心实现逻辑**：
- 使用Win32 API函数`keybd_event`模拟键盘事件
- 使用`SetWindowText`设置窗口文本
- 处理不同窗口类型的输入方式

**关键类**：`InputSimulator`

### 3.4 UI模块

**功能描述**：提供用户界面，包括系统托盘、悬浮按钮和登录界面。

**职责划分**：
- 系统托盘图标和上下文菜单
- 悬浮按钮（生成密码和提取密码）
- 登录界面
- 通知窗口

**核心实现逻辑**：
- 使用Windows Forms创建界面
- 响应按钮点击事件
- 显示系统托盘提示
- 处理用户登录验证

**关键类**：`TrayIcon`, `FloatingButton`, `LoginForm`, `NotificationForm`

### 3.5 工具模块（Utils）

**功能描述**：提供日志记录和全局状态管理功能。

**职责划分**：
- 记录日志信息
- 管理全局状态（登录信息、服务器地址等）

**核心实现逻辑**：
- 使用单例模式管理全局状态
- 提供不同级别的日志记录
- 确保线程安全

**关键类**：`Logger`, `GlobalState`

## 4. 数据模型设计

### 4.1 存储方式

项目使用以下存储方式：

1. **Windows NTFS备用数据流**：用于存储文档密码和UID
   - 密码存储路径：`{文件路径}:WpsPasswordManager`
   - UID存储路径：`{文件路径}:WpsPasswordManagerUid`

2. **本地JSON文件**：用于存储缓存和配置信息
   - `uid_cache.json`：存储文档路径和对应的UID
   - `login_cache.json`：存储登录信息（已移至内存存储）

### 4.2 核心数据对象

| 数据对象 | 类型 | 描述 | 存储方式 |
|---------|------|------|----------|
| 文档路径 | string | 文档的完整路径 | UID缓存文件 |
| 密码 | string | 文档的加密密码 | NTFS备用数据流 |
| UID | string | 文档的唯一标识符 | NTFS备用数据流 + UID缓存文件 |
| 登录信息 | 复杂对象 | 包含用户名、token、服务器地址等 | 内存存储 |

### 4.3 数据流转说明

1. **密码生成流程**：
   - 用户点击悬浮按钮的"生成密码"按钮
   - `PasswordGenerator`生成随机密码
   - `InputSimulator`将密码填充到输入框
   - 监控应用按钮点击事件
   - 文档关闭后，将密码写入文档元数据

2. **自动填充流程**：
   - 监控到解密窗口
   - 从文档元数据中读取密码
   - `InputSimulator`将密码填充到输入框并模拟确认

3. **登录流程**：
   - 用户输入登录信息
   - 发送登录请求到服务器
   - 存储token和用户信息到全局状态

## 5. API接口文档

### 5.1 登录接口

**接口路径**：`/account/login`

**请求方法**：POST

**请求参数**：
| 参数名 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| account | string | 是 | 用户名 |
| password | string | 是 | 密码 |

**返回格式**：
```json
{
  "status": 200,
  "message": "登录成功",
  "date": "2026-03-19 12:00:00",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
```

**错误码**：
| 错误码 | 描述 |
|--------|------|
| 400 | 请求参数错误 |
| 401 | 用户名或密码错误 |
| 500 | 服务器内部错误 |

**示例**：
```bash
POST http://localhost:8080/account/login
Content-Type: application/json

{
  "account": "admin",
  "password": "password123"
}
```

## 6. 开发环境配置指南

### 6.1 环境要求

- Windows 10或Windows 11操作系统
- .NET 6.0 SDK
- Visual Studio 2022或更高版本
- WPS Office 2019或更高版本

### 6.2 依赖安装

1. 克隆项目代码到本地
2. 打开Visual Studio，加载项目文件 `WpsPasswordManager.csproj`
3. 项目会自动安装以下依赖：
   - DocumentFormat.OpenXml 2.20.0

### 6.3 配置文件设置

项目无需特殊配置文件，所有配置通过代码和内存存储管理。

### 6.4 启动方法

1. 在Visual Studio中设置启动项目为 `WpsPasswordManager`
2. 按F5或点击"开始调试"按钮启动项目
3. 首次运行时会显示登录界面，输入正确的登录信息
4. 登录成功后，插件会在系统托盘中显示图标

## 8. 关键业务流程说明

### 8.1 密码生成和填充流程

1. **触发条件**：用户打开WPS文档的密码加密窗口
2. **流程步骤**：
   - 监控模块检测到密码加密窗口
   - 显示悬浮按钮
   - 用户点击"生成密码"按钮
   - 密码生成器生成随机密码
   - 输入模拟器将密码填充到输入框
   - 监控应用按钮点击事件
   - 文档关闭后，将密码写入文档元数据

### 8.2 自动填充流程

1. **触发条件**：用户打开加密的WPS文档
2. **流程步骤**：
   - 监控模块检测到密码解密窗口
   - 从文档元数据中读取密码
   - 输入模拟器将密码填充到输入框
   - 模拟按Enter键确认

### 8.3 文档关闭后密码写入流程

1. **触发条件**：用户关闭加密的WPS文档
2. **流程步骤**：
   - 监控线程检测到文档关闭
   - 从缓存中获取密码
   - 将密码写入文档元数据
   - 保存文档UID到元数据

### 8.4 登录流程

1. **触发条件**：首次运行插件或登录状态失效
2. **流程步骤**：
   - 显示登录界面
   - 用户输入登录信息
   - 发送登录请求到服务器
   - 存储token和用户信息到全局状态

### 8.5 监控WPS进程流程

1. **触发条件**：插件启动
2. **流程步骤**：
   - 启动监控线程
   - 定期检查WPS进程是否运行
   - 检测密码相关窗口
   - 处理窗口事件

## 9. 常见问题解决方案

### 9.1 窗口定位失败

**问题描述**：无法找到WPS密码窗口或输入框

**解决方案**：
- 尝试多种窗口类名和标题查找
- 枚举所有WPS窗口，确保不遗漏
- 使用UI Automation作为备用方法
- 增加日志记录，便于调试

### 9.2 密码获取失败

**问题描述**：无法从密码输入框获取密码

**解决方案**：
- 尝试使用多种方法获取输入框文本
- 使用UI Automation作为备用方法
- 增加重试机制，确保获取到密码

### 9.3 元数据写入失败

**问题描述**：无法将密码写入文档元数据

**解决方案**：
- 使用NTFS备用数据流存储
- 增加重试机制，处理文件锁定情况
- 提供外部存储作为备用方案

### 9.4 登录失败

**问题描述**：无法登录到服务器

**解决方案**：
- 检查网络连接
- 验证服务器地址和端口设置
- 检查用户名和密码是否正确
- 增加错误处理和提示

### 9.5 性能问题

**问题描述**：插件运行缓慢或占用资源过多

**解决方案**：
- 优化监控线程的扫描间隔
- 减少不必要的窗口枚举
- 使用高效的窗口查找方法
- 清理不再使用的资源

### 9.6 兼容性问题

**问题描述**：插件在某些WPS版本或Windows版本上不工作

**解决方案**：
- 支持多种窗口类型和类名
- 适应不同的DPI设置
- 处理不同版本的WPS窗口结构
- 增加兼容性测试
