### 方案二：重写 `WndProc` 拦截双击消息（最彻底）

这是“高级开发人员”常用的方法。`TreeView` 在双击 CheckBox 区域时，会产生一个特定的 Windows 消息。我们可以拦截这个消息，当检测到点击的是 CheckBox 且父节点已勾选时，直接丢弃该消息。

你可以创建一个自定义的 TreeView 类：

C#

```
public class MyTreeView : TreeView
{
    private const int WM_LBUTTONDBLCLK = 0x0203;

    protected override void WndProc(ref Message m)
    {
        if (m.Msg == WM_LBUTTONDBLCLK)
        {
            var pos = PointToClient(Cursor.Position);
            var info = HitTest(pos);

            // 如果双击的是 CheckBox 区域
            if (info.Location == TreeViewHitTestLocations.StateImage)
            {
                // 如果父节点已勾选，直接拦截双击消息，不让它变成“勾选”动作
                if (info.Node?.Parent != null && info.Node.Parent.Checked)
                {
                    return; // 拦截消息，不向上传递
                }
            }
        }
        base.WndProc(ref m);
    }
}

```
