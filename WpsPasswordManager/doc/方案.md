## 方案一：使用 NPOI（开源、免费、无需安装 Office）

**推荐等级：⭐⭐⭐⭐** 这是后台程序最常用的方案。NPOI 是一个开源库，支持在没有安装 Microsoft Office 的情况下读取 Office 文件。

### 实现逻辑

对于加密文件，NPOI 在尝试打开流时会要求提供密码。如果密码错误，会抛出 `EncryptedPowerPointFileException` 或类似的异常。

### 代码示例 (以 Excel 为例)

C#

```
using NPOI.SS.UserModel;
using NPOI.XSSF.UserModel;
using System.IO;

public bool VerifyExcelPassword(string filePath, string password)
{
    try
    {
        using (FileStream fs = new FileStream(filePath, FileMode.Open, FileAccess.Read))
        {
            // 如果密码错误，这里会抛出异常
            IWorkbook workbook = WorkbookFactory.Create(fs, password);
            return true; 
        }
    }
    catch (NPOI.EncryptedDocumentException)
    {
        // 密码错误
        return false;
    }
    catch (Exception ex)
    {
        // 处理其他异常（如文件损坏、IO错误）
        return false;
    }
}
```
